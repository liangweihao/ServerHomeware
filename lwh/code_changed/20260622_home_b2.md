# 首页 B2 改版 — 技术文档

## 一、改动说明

按 [home-and-list-redesign.md](../doc/design/home-and-list-redesign.md) Phase B2 落地。

### UI

1. **StatCard**：白底 + 左侧 4px 语义色条 + Material Icon（替代 emoji / 整块浅色底）
2. **区块标题**：去掉 ⚠️📍📅；统一 `_buildSectionHeader`
3. **今日待办条** `TodayAlertBanner`：仅当 `expiringCount + lowStockCount > 0` 显示，点击 → `/alerts`
4. **AppBar**：去掉 🏠；家庭名可点 → 用户面板；通知图标 `notifications_outlined` + 真实 Badge
5. **快捷查看**：增加「全部空间 →」链到 `/locations`
6. **动态卡片**：轻阴影与列表风格一致

### 文件

- `home_page.dart`
- `stat_card.dart`（API：`icon` + `accentColor`）
- `today_alert_banner.dart`（新建）
- `shimmer_loading.dart`（ShimmerStatCard 对齐新布局）

### 刷新

下拉刷新增加 `invalidateAlertProviders(ref)`。
