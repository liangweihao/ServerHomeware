## 三、设计定位（v1 定稿）

| 项目 | 说明 |
|------|------|
| 气质 | **更萌** — 超大眼、腮红、头身约 1:1，婴儿感 Q 版 |
| 风格 | 扁平矢量卡通，**vividClean 糖果轻点** |
| 用途 | 问管家入口、会话页、空状态、Rive 骨骼参考 |
| 三视图 | 正（表情）/ 侧（清单板轮廓）/ 背（小背包库存语义） |

### 造型要点

- **头**：圆头盔 + 双触角（珊瑚球），天线可独立做 idle 摇摆
- **脸**：大眼 + 高光 + 珊瑚腮红；嘴型 2～3 帧即可
- **胸**：圆角房子徽章（心形窗可选）→ 家庭库存
- **侧**：清单板挂腰 → 记/查
- **背**：圆角小背包 → 物品收纳隐喻
- **Pose**：三视图均为 **标准待机**，脚线对齐，等比例

### 10.2 问管家（Phase 1 已有能力）

| # | 产品场景 | 用户/系统触发 | 主视图 | 动画名 | 动作描述 | 出现位置 | 优先级 |
|---|----------|---------------|--------|--------|----------|----------|--------|
| 1 | 首次进入问管家 | 打开 `/assistant` 第一次 | **正** | `wave` → `idle` | 挥手说你好，再恢复呼吸 | 会话顶栏 / 首条气泡旁 | **P0** |
| 2 | 等待用户输入 | 无输入、未 loading | **正** | `idle` | 轻微上下呼吸 + 双触角慢摆 | 顶栏头像、输入框左侧 | **P0** |
| 3 | 正在理解问题 | 用户点发送后 | **正** | `think` | 眼上看、清单板微抬（或整图慢晃） | 顶栏 / 气泡旁 loading | **P0** |
| 4 | 查到了（有列表） | `AssistantReply` 带 items | **正** | `happy` → `talk` | 眯眼跳一下，再指下方结果卡 | 助手气泡上方 | **P0** |
| 5 | 查到了（纯文字） | 如「牛奶在冰箱」 | **正** | `talk` | 嘴型开合 2 帧 + 胸章闪一下 | 助手气泡旁 | **P0** |
| 6 | 没听懂 | `intent == unknown` | **正** | `confused` | 歪头 + 问号气泡 | 助手回复旁 | **P0** |
| 7 | 查空间无物品 | 「厨房有什么」结果空 | **正** | `confused` → `idle` | 摊手/困惑，再恢复 idle | 空结果文案旁 | P1 |
| 8 | 临期/低库存/待处理 | 三类提醒类查询 | **侧** | `clipboard_show` | 侧身举清单板，板上有色点（语义色） | 结果列表标题旁 | P1 |
| 9 | 点击建议 Chip | 点「厨房有什么」等 | **正** | `think` | 同 #3，短促版 | 顶栏 | P1 |

**Phase 1 程序员映射示例**：

```dart
enum GuanguanState { idle, think, talk, happy, confused, wave }

// _busy == true        → think
// 回复带 items         → happy → talk
// unknown / helpReply  → confused
// initState 首次       → wave → idle
```
