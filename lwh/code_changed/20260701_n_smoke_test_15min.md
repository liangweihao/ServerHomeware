# N：15 分钟冒烟测试清单

> 适用版本：工具风主题 + F/M/L 主路径完成后  
> 环境：真机或模拟器 ×1（双设备项可选 +5 分钟）  
> 前置：后端已启动、账号已登录同一家庭、客户端 **热重启**（非仅热重载）

---

## 0. 准备（约 1 分钟）

| 检查项 | 通过 |
|--------|------|
| 后端 `http://localhost:8000` 或 `env.local.json` 指向可达 API | ☐ |
| 登录账号有昵称（Profile 可见） | ☐ |
| App 热重启后首页正常加载 | ☐ |

**失败时**：先看网络/API 地址，不要继续测业务路径。

---

## 1. 首页 → 提醒（约 2 分钟）

| # | 操作 | 预期 | 通过 |
|---|------|------|------|
| 1.1 | 首页有待办时，点 **今日摘要** 整卡 | 进入提醒中心 | ☐ |
| 1.2 | 点 Chip **已过期** 或 **临期** | 提醒中心 **过期 Tab** 已选中 | ☐ |
| 1.3 | 点 Chip **低库存** | 提醒中心 **库存 Tab** 已选中 | ☐ |
| 1.4 | 返回首页，下拉刷新 | 四分区/摘要正常，无崩溃 | ☐ |

---

## 2. 提醒 → 记消耗闭环（约 3 分钟）

| # | 操作 | 预期 | 通过 |
|---|------|------|------|
| 2.1 | 提醒中心 → 过期项 → **今天用掉** | SnackBar 成功，该项减少或消失 | ☐ |
| 2.2 | 点击另一条 **过期提醒卡片** | 进详情 + **自动弹出记消耗** + 顶栏提醒 Banner | ☐ |
| 2.3 | Banner 点 **记 1 件** | 无二次弹窗，数量更新 | ☐ |
| 2.4 | 通知中心（首页铃铛）点一条过期通知 | 同上进入详情闭环 | ☐ |

## 3. 录入 + 编辑（约 4 分钟）

| # | 操作 | 预期 | 通过 |

| 3.6 | 信息步可见 **当前剩余** 灰色提示 | 文案正确 | ☐ |

## 6. 通过标准

- **冒烟通过**：§1–§5 中 **≥ 90%** 用例通过，且 **§2、§3.1、§4.2 必过**
- **阻塞缺陷**：崩溃、无法登录、无法保存物品、记消耗无反应 → 立即停止，记录步骤 + 截图/log
