# 用户个人面板功能变更记录

## 概述

根据设计文档 `/Users/lwh/Desktop/Project/ServerHomeWare/doc/appPhase/Phase 8: 用户信息编辑页.md`，实现用户个人面板功能。

## 核心改动

### 1. 交互方式修改

**原设计**：首页头像点击 → 右侧滑出面板
**新设计**：首页头像点击 → 跳转到个人面板新页面

### 2. 创建个人面板页面

**文件**: `lib/presentation/profile/profile_panel_page.dart`

**页面结构**:
- **头部区域**：大头像80×80、昵称、手机号、编辑资料按钮
- **当前家庭卡片**：家庭名、成员头像列表（最多显示5个）、统计摘要、邀请码（复制/刷新）、管理成员/切换家庭按钮
- **我的贡献区域**：录入数量、消耗记录、贡献度进度条、激励文案
- **功能入口列表**：设置、盘点任务、数据导出、帮助与反馈、关于 HomeStock
- **退出登录按钮**：红色文字，弹出确认对话框

### 3. 修改首页头像交互

**文件**: `lib/presentation/home/home_page.dart`

**改动**:
- 添加用户头像按钮（32×32圆形，渐变色背景+首字母）
- 点击头像跳转到 `/profile/panel`
- 添加通知按钮（带未读红点）

### 4. 添加路由配置

**文件**: `lib/core/router/app_router.dart`

**新增路由**:
- `/profile/panel` - 个人面板页面

### 5. 创建家庭信息服务

**文件**: `lib/core/services/family_service.dart`

**方法**:
- `getCurrentFamily(userId)` - 获取当前家庭信息
- `getInviteCode(familyId)` - 获取邀请码
- `refreshInviteCode(familyId)` - 刷新邀请码

### 6. 创建贡献度服务

**文件**: `lib/core/services/contribution_service.dart`

**方法**:
- `getUserContribution(userId)` - 获取用户贡献数据

## 导航流程

```
首页头像点击
    ↓
/profile/panel（个人面板页）
    ↓
[编辑资料] → /profile/edit
[管理成员] → /profile/family  
[切换家庭] → 底部弹窗选择
[设置] → /profile/notification-settings
[退出登录] → 确认弹窗 → /login
```

## 测试点

1. **面板页面打开**: 点击头像跳转到个人面板页
2. **面板内容**: 显示用户信息、家庭信息、贡献度数据
3. **家庭信息**: 显示家庭名和成员头像、复制邀请码、刷新邀请码、管理成员、切换家庭
4. **功能入口**: 点击设置跳转、数据导出提示、帮助与反馈提示
5. **退出登录**: 弹出确认对话框，确认后清除数据并跳转登录页
6. **编辑资料**: 点击编辑资料按钮跳转到编辑页

## 注意事项

1. 页面支持返回上一页（系统返回键或导航返回）
2. 退出登录会清除本地存储的用户信息
3. 邀请码刷新后旧码失效
4. 所有交互都有相应的 Toast 提示
