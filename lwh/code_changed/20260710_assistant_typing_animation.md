# 问管管 LLM 等待动画（Candy Light）

## 技术开发文档

### 问题

发送消息后 LLM 响应需数秒，界面无反馈，用户以为卡住。

### 设计方案（糖果轻点）

| 元素 | 说明 |
|------|------|
| 气泡位置 | 左对齐，与管管回复气泡一致 |
| 糖果圆点 | 珊瑚 / 青绿 / 蜜糖三色错峰跳动 |
| 管管头像 | idle 序列帧 + 轻微上下浮动 |
| 轮播文案 | 「管管正在想…」「翻翻家里库存…」「马上回复你～」 |
| 顶栏联动 | 思考时副标题变珊瑚色「正在帮你查…」，头像呼吸缩放 |

### 改动点

| 文件 | 改动 |
|---|---|
| `widgets/assistant_typing_indicator.dart` | **新增** 思考中动画组件 |
| `widgets/assistant_mascot_header.dart` | 新增 `isThinking`，呼吸动画 + 副标题切换 |
| `assistant_chat_page.dart` | `_busy` 时在列表末尾展示 typing 指示器 |

### 影响范围

- 仅问管管会话页等待态 UI
- 尊重系统「减少动画」设置（`disableAnimations` 时圆点静止）

---

## 提测开发文档

### 测试点

| 场景 | 预期 |
|---|---|
| 发送任意问题 | 立即出现左下角思考气泡 + 三色跳动圆点 |
| 等待 2s+ | 轮播文案切换 |
| 顶栏 | 副标题变「正在帮你查…」，管管头像轻微呼吸 |
| 收到回复 | 思考气泡消失，正常展示回复 |
| 发送按钮 | 等待中显示转圈，输入框禁用 |

### 验证方式

Flutter 热重载后，助手页提问，观察 2–5 秒等待过程动画与顶栏联动。
