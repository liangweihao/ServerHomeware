## 〇、锁定配色 — ③ 糖果轻点（落地真源）

> 以下色值为 **Flutter `Color(0xFF...)` 真源**，与效果图一致；禁止组件内再随意改 hex。

### 基底（与现 `utilityClean` 清爽化后几乎相同）

| Token | 色值 | 说明 |
|-------|------|------|
| `scaffoldBackground` | `#FAFAF8` | 页面底（现已是暖灰白） |
| `card` / AppBar | `#FFFFFF` | 白卡、白顶栏 |
| `homeDivider` | `#EEEEEE` | 卡片描边 |
| `textPrimary` | `#333333` | 标题、物品名 |
| `textSecondary` | `#666666` | 副信息、图标默认 |
| `textHint` | `#999999` | 占位、未选中 |

### 主色（仅链接 / 选中描边 / 进度条，不铺底）

| Token | 色值 | 用途 |
|-------|------|------|
| `primary` | `#FF6B5A` | 链接、「查看全部」、选中 Chip 描边 |
| `primaryDark` | `#E85A4A` | 按下态 |
| `accentHighlight` | `#FFDA44` | **仅** FAB、首页「+」 |
| `onAccentHighlight` | `#333333` | 黄底上的图标/字 |

### 功能点缀色（宫格 / 概览顶条 — 固定映射，保证「多样」）

| Token | 色值 | 绑定功能 |
|-------|------|----------|
| `accentCoral` | `#FF6B5A` | 物品、协作 |
| `accentTeal` | `#2BB8A3` | 空间相关（可选） |
| `accentSky` | `#4A9FE8` | 统计、通知 |
| `accentViolet` | `#8B7FD4` | 盘点 |
| `accentAmber` | `#F5A623` | 购物、临期语义 |
| `accentRose` | `#E85D8A` | 装饰/次要入口 |

### 语义色（物品标签 — 保持用户认知，与现网一致）

| 状态 | 字色 | 底色（12% alpha） |
|------|------|-------------------|
| 已过期 | `#F44336` danger | `#F44336` @ 12% |
| 临期 | `#FF9800` warning | `#FF9800` @ 12% |
| 低库存 | `#4A9FE8` accentSky | `#4A9FE8` @ 12% |
| 正常 | `#4CAF50` success | `#4CAF50` @ 12% |

### ③ 糖果轻点 — 三条渲染规则（与效果图对齐）

1. **图标圆底**：40–42px 圆角方块，**饱和色填充 100%** + **白色图标**（不是灰底彩图标）
2. **标签 Pill**：饱和字色 + 同色 **12% 浅底**（`TagChip` / `AppReasonTag` 已有，略提高饱和度感知）
3. **选中 Chip**：白底 + **1.5px 饱和描边** + 饱和字（不要橙底铺色）

## 〇.1 效果图 vs 真机 — 会不会差很多？

| 维度 | 预期一致度 | 说明 |
|------|------------|------|
| 页面底色、白卡、布局 | **95%+** | 结构不变，与现 App 相同 |
| 标签/理由 Pill 彩色 | **90%** | 代码已是 `color + 12% 底`，仅微调色值 |
| 宫格/快捷入口图标 | **85%** | 需改「灰底彩标 → 饱和底白标」，差异最明显的一处 |
| 筛选 Chip 选中态 | **85%** | 需改选中描边色为 `primary` |
| 个人中心头图 | **95%** | 已纯白，与③一致 |
| AI 效果图整体气质 | **70–80%** | 效果图无真实数据密度、字体渲染、长列表滚动 |

**结论**：

- 相对 **AI 效果图**：不会 100% 像素级一样，但 **色相、面积比例、干净度** 可对齐；真机往往更「素」一点（因为列表信息多）。
- 相对 **你现在 App（清爽化后）**：**不会翻天覆地** — 布局、白卡、灰底不变；主要差在 **图标底从灰变饱和、标签/Chip 更鲜艳**，整体约 **20–30% 视觉变化**，集中在点缀色上。

## 一、你的诉求（归纳）

| 关键词 | 设计翻译 |
|--------|----------|
| 颜色不要太重 | 页面/卡片 **大面积保持白/米白**；禁止整页铺色、渐变头图、橙底 Chip |
| 有 UI 特色 | **功能色分区** + **小面积高饱和点缀**（图标、标签、顶条） |
| 鲜艳而浓 | 饱和色用在 **8–15% 面积**（标签、图标、3px 色条），不是整卡染色 |
| 多样而干净 | **多色相**（珊瑚/青/琥珀/紫…）但 **同一套白卡结构** |

一句话：**白底画布 + 彩虹点缀 + 结构统一。**

| 个性 | 工具感强、偏单调 | **多彩但仍整洁** |

## 三、三套子风格（供选一）

### ① 珊瑚点睛 Coral Pop（偏暖、有温度）

- 页面底：`#FAFAF8`
- 主操作/FAB：`#FF6B4A` 珊瑚 + `#FFDA44` 黄（仅 FAB）
- 功能图标色：珊瑚 / 青 `#2BB8A3` / 琥珀 `#F5A623` / 紫 `#8B7FD4` / 玫 `#E85D8A`
- 图标底：对应色 **12% 透明度**，卡片仍白
- 适合：要暖、要活泼、家庭感

### ② 青松光谱 Sage Spectrum（偏自然、清爽）

- 页面底：`#FAFAF8`
- 主色：`#3A9B8A` 青松（见 `visual-refresh.md`）
- 功能色：森绿 / 天蓝 / 麦金 / 藕紫
- 适合：健康、收纳、「家里井井有条」

### ③ 糖果轻点 Candy Lite（最有辨识度）

- 页面底：`#FFFFFF` / `#FAFAF8`
- 彩色 **只出现在**：筛选 Chip 描边、列表左 3px 色条、40px 圆角图标底（饱和填充）
- 文字始终 `#333`，数字不染色
- 适合：要「一眼有性格」但仍干净

# 用法
iconWell(color)      → color @ 12% 作底，color @ 100% 作图标
tagVivid(semantic)   → 语义色字 + 语义色 @ 12% 底，字重 w600

### 硬性禁止（保证「不重」）

- ❌ 头图渐变、点阵、装饰大圆
- ❌ `primaryLighter` 铺整卡/整行
- ❌ 选中 Chip 大面积橙底（改为白底 + 饱和描边）
- ❌ 宫格大卡 tint 渐变底

### 鼓励（保证「鲜艳多样」）

- ✅ 每个快捷入口固定一种 `accent*` 色
- ✅ 物品列表理由标签用饱和 Pill（红/橙/蓝/绿）
- ✅ 首页分区标题下 3px 色条区分模块
- ✅ 分类 Chip 用 DB 分类色浅底 + 饱和字

## 六、提测目视点

1. 首屏 80% 面积是白/米白
2. 颜色集中在标签、图标、细条上，能感到「多彩」
3. 没有整页橙/黄/绿 wash
4. 与卡通主题切换后，卡通风仍走原分支
