# 卡通主题第三期 — 细节打磨

## 改动摘要

在第二期马卡龙 + 吉祥物基础上，统一全链路卡通组件，减少「只有首页像卡通」的割裂感。

### 1. 全局组件
- `CartoonAppBarIcon` — 圆形贴纸图标按钮（搜索/通知）
- `CartoonTabBar` — 提醒中心贴纸 Tab 栏（emoji + 滑动块）

### 2. 首页
- 家庭名贴纸标题、AppBar 头像贴纸环
- 统计卡 / 空间卡 / 动态 **错开入场动画**
- 空间卡按序号 **马卡龙底色**
- 动态项 emoji 气泡 + 分割线
- 区块标题「查看全部」改为贴纸按钮

### 3. 物品页
- 筛选 Chip 增加 emoji（🌈✅📭⏰🗑️）
- 分类 Chip 卡通贴纸化

### 4. 提醒页
- 标题「🔔 提醒中心」+ 卡通 Tab
- 提醒列表入场动画

### 5. 我的
- 设置项 emoji 放入贴纸小方框

### 6. 微调
- 统计卡倾斜角略减小，更稳
- 问候条增加 👋

## 提测
1. 首页：AppBar 圆形按钮、家庭名贴纸、四宫格/空间/动态入场
2. 物品：筛选 emoji chip
3. 提醒：底部贴纸 Tab + 列表滑入
4. 我的：设置行左侧 emoji 方框
