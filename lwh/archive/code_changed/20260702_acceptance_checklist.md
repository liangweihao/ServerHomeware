## 一、Phase A — 稳基础（P0 必过）

### A1. WebSocket 实时同步

> 设备 A 操作，设备 B 观察（或反过来）。等待 ≤5 秒。

| # | 操作 | 预期 | P | 通过 | 备注 |
|---|------|------|---|:----:|------|
| A1-1 | 两设备登录 | 个人中心显示「实时同步已连接」 | P0 | ☐ | |
| A1-2 | 客户端日志 | `[RealtimeSync] INFO: 握手成功` 或 `连接` | P0 | ☐ | |
| A1-3 | A 记消耗 1 件 | A 首页/提醒数量更新 | P0 | ☐ | |
| A1-4 | B **不操作** 等 ≤5s | B 首页/Badge/物品数量**自动**刷新 | P0 | ☐ | |
| A1-5 | B 打开 Profile 家庭协作 | 可见 A 的操作动态 | P1 | ☐ | |
| A1-6 | A 登出 | 状态变「未连接」；日志 `已断开` | P1 | ☐ | |
| A1-7 | 杀后端 → 再启动 | 客户端「重连中」→「已连接」 | P1 | ☐ | |
| A1-8 | A 断网记消耗 → 联网 | 离线记录补推；B 刷新后可见 | P1 | ☐ | |

**后端日志应出现**：`WebSocket 握手成功` / `WebSocket 广播 event=items_changed`

**失败排查**：
1. 后端必须**重启**（WS 路由 + 中间件修复需 reload）
2. WS URL：`ws://<host>:8000/api/v1/ws/notifications?token=...`
3. 防火墙 / 路由器是否拦截 WebSocket
4. 仍 404 → 确认代码含 `ws_router` 且进程已重启
