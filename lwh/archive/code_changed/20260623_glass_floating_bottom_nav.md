# 玻璃拟态底栏 — 原生式图标+标签

## 概述

贴底全宽磨砂底栏，采用 **iOS 原生 Tab 结构**（图标 + 小标签），去掉横条/光晕/圆框等额外装饰，减少小气感。

## 视觉

```
┌────────────────────────────────────┐
│  🏠      📋      🔔      👤        │
│ 首页    物品    提醒    我的        │
└────────────────────────────────────┘
```

| 项 | 参数 |
|----|------|
| 高度 | 64px + 安全区 |
| 模糊 | sigma 24 |
| 选中 | 实心图标 + 标签加亮（无滑动指示器） |
| 未选中 | 线框图标 + 半透明标签 |

## 版本

- v5：原生式图标+标签（当前）
- v4：滑动底线（已废弃）
- v3 及更早：光晕/胶囊（已废弃）
