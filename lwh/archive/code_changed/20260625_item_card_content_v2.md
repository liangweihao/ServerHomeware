# 物品列表卡片内容层 v2 卡通强化

## 技术开发文档

### 目标

在 v1（贴纸外框 + 基础标签）基础上，进一步解决「外壳卡通、内容像普通 ListTile」的问题，使物品页与首页统计卡片的卡通浓度对齐。

### 改动点

#### 1. `cartoon_ui.dart`

- `CartoonStickerBadge` 增强：
  - 支持 `emoji` 前缀（emoji 与文案分开展示）
  - `compact` 模式（元信息行用小描边/小阴影）
  - 字重 w900、描边 2.5px
- 新增 `CartoonInnerPanel`：白底内层贴纸区，与外层马卡龙底形成双层层次

#### 2. `item_card.dart` 布局重构

| 层级 | 说明 |
|------|------|
| 外层 | 按 `item.id` 轮换马卡龙色 + 描边；轻微 `Transform.rotate` 手贴感 |
| 左侧 | 62px 缩略图白底贴纸框；无图时按名称猜 emoji（🍎/💊/📦） |
| 内层 | `CartoonInnerPanel` 包裹全部文字信息 |
| 标题 | w900、15px、最多 2 行 |
| 元信息 | `Wrap` 行：🏷️ 分类 / 🏪 品牌 / 📍 位置，各为独立 compact 贴纸 |
| 底行 | 📦 数量（大标签）+ 右侧过期/状态标签 |

### 影响范围

- 仅物品列表 `ItemCard` 及复用 `CartoonStickerBadge` 的其他页面（视觉略强，兼容）
- 不影响数据逻辑与点击行为

## 提测开发文档

### 测试点

1. 物品列表：每项应有 **外层彩色 + 内层白底** 双层结构
2. 标题加粗加大；分类/品牌/位置为独立 emoji 贴纸 Chip
3. 底行左侧数量标签、右侧过期/状态标签
4. 卡片有极轻微倾斜（交替方向）
5. 无图物品显示情境 emoji 而非统一 📦
6. 已丢弃/已用完物品透明度降低仍可读
