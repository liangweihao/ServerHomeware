# 物品列表 B1 改版 — 技术文档

## 一、实现说明

按 [home-and-list-redesign.md](../doc/design/home-and-list-redesign.md) Phase B1 落地。

### 改动点

1. **AppBar**：标题「物品」+ 右侧扫码 `Icons.qr_code_scanner_outlined` → `/items/scan`
2. **搜索区**：与背景融合（`gray100` 填色），右侧 **筛选** `Icons.tune` 打开 `FilterBottomSheet`
3. **状态 Chip**：选中 `primaryLighter` + `primaryDark` 字；未选中 `gray100`
4. **分类 Chip**：打开 `CategorySelector`；选中可 × 清除；筛选含子分类
5. **高级筛选**：位置、排序、即将过期、一级分类与 Provider 联动
6. **ItemCard**：阴影统一 `0.04`
7. **FAB**：修复滚动 >200 时切换「回顶」的 `ScrollController` 监听

### 新增 Provider

- `expiringSoonFilterProvider`
- `locationFilterProvider`
- `itemSortProvider`
- `categoryFilterLabelProvider`

### 修改文件

- `item_list_page.dart`
- `filter_bottom_sheet.dart`（Chip 样式）
- `item_card.dart`（阴影）
