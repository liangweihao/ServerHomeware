# HomeStock 主题与产品交互 — 三方 App 借鉴优化方案

> 日期：2026-07-01  
> 状态：**产品/设计规范**（非业务照搬）  
> 参考 App：书旗、大众点评、闲鱼（反编译 UX 分析）  
> 适用：**HomeStock / HomeWare 家庭物品管家**

---

## 〇、先说清楚：借什么、不借什么

| 借 | 不借 |
|----|------|
| 信息怎么排、页面怎么逛、怎么降低操作门槛 | 对方 App 的行业分类、文案、Mock 数据 |
| 分区 Feed、横滑预览、搜索结构、列表三态 | 「家政」「托管」「门店系统」等业务模块 |
| 卡片层级（图→标题→状态→辅助信息） | 评分、距离、团购、促销、UGC 社区 |
| 发布/录入的分步与入口设计思路 | 闲鱼式二手交易、点评式商户详情 |

**原则一句话**：用成熟内容 App 的 **壳（主题 + 交互范式）**，装家庭物品管理的 **核（录入、库存、过期、位置、家庭）**。

## 一、我们的产品是什么（锚点）

来源：[`doc/product/vision.md`](../../doc/product/vision.md)、[`20260630_home_single_page_sections.md`](20260630_home_single_page_sections.md)

### 1.1 一句话定位

> **家庭物品的全生命周期管家** — 知道有什么、在哪、还能用多久、什么时候该处理。

### 1.2 核心价值（用户为什么打开 App）

| 价值 | 用户问题 | 产品响应 |
|------|----------|----------|
| 省心 | 什么东西快过期了？ | 过期 / 临期提醒 |
| 省钱 | 是不是买重了、浪费了多少？ | 库存、消耗、统计 |
| 省时 | 创可贴放哪？家里还有牛奶吗？ | 搜索、位置、列表 |
| 协作 | 家人买的谁录的？ | 家庭共享、贡献度 |

### 1.3 已交付 / 进行中的形态（代码为准）

- **单页首页**：顶栏（头像 | 搜索 | +）+ 四分区横滑（已过期 / 临期 / 库存不足 / 全部）
- **无底部 Tab**：物品、提醒、设置从个人中心或搜索进入
- **主题**：`communityWarm` 米白居家暖色（替代卡通珊瑚风）
- **数据**：物品、提醒走 API + 本地 Drift 缓存

### 1.4 与「社区便民规划稿」的关系

[`20260630_community_home_ui_spec_and_plan.md`](20260630_community_home_ui_spec_and_plan.md) 中的托管/家政/门店是 **探索性规划**，**不是当前产品核**。  
若未来做社区延伸，应作为 **独立 Epic** 评审，不能覆盖 HomeStock 主路径，更不能在没 API 时硬塞 Mock 分类。

## 三、主题借鉴（Visual）— 贴合 HomeStock

### 3.1 气质定位

HomeStock 是 **工具型家庭管家**，不是本地生活市场，也不是内容社区。

| 维度 | 目标气质 | 参考来源 | 避免 |
|------|----------|----------|------|
| 整体 | 干净、居家、可信赖 | 书旗留白 + 自家 `communityWarm` | 点评促销橙、闲鱼黄 |
| 背景 | 米白 `#FAF7F2` + 模块浅米 `#F5F0E8` | 已落地 palette | 大面积渐变、贴纸描边 |
| 主色 | 暖棕杏 `#C8956A`（居家）或文档青松 `#3A9B8A`（清爽） | 需产品定一条主线 | 与语义红/橙抢戏 |
| 卡片 | 白底、圆角 12、轻投影 | 三者共通 | 卡通粗描边 |
| 语义色 | 红过期、橙临期/低库存、绿正常 | 自家设计规范 | 用标签色代替语义 |

### 3.2 主题 Token 建议（与物品语义绑定）

```
background          #FAF7F2   页面底
sectionBackground   #F5F0E8   首页分区底
card                #FFFFFF   卡片
textPrimary         #3D3229   标题（物品名）
textSecondary       #8B7355   查看全部、位置
textHint            #B0A090   搜索占位

语义标签（示例）：
  已过期   字 #8B4A42  底 #F5E8E6
  临期     字 #8B6914  底 #F5F0E0
  低库存   字 #4A6B8A  底 #E6EDF5
  分类     用 DB 分类色，不与主色混淆
```

### 3.3 全站主题统一范围（优先级）

| 优先级 | 页面 | 现状 | 目标 |
|--------|------|------|------|
| P0 | 首页、搜索、个人中心面板 | 部分已暖色 | 全部 `communityWarm`，无 CartoonScaffold |
| P1 | 物品列表、详情、添加入库 | 卡通风 | 迁移暖色 + P5/P6 交互 |
| P2 | 提醒中心、位置、购物清单 | 卡通风 | 同上 |
| P3 | 登录注册 | auth 包装 | 可保留轻度品牌差异 |

## 四、产品形态建议（Form）— 只围绕物品

### 4.1 首页：单页「今天要处理什么」

**形态**（已实现方向，应强化而非替换）：

```
┌─────────────────────────────────────┐
│ [头像]  [🔍 搜索物品、位置、品牌…]  [+] │
├─────────────────────────────────────┤
│  需要关注                            │  ← 可选一行摘要（书旗/点评式 weak 引导）
│  · 2 件已过期 · 3 件临期              │     点进提醒中心
├─────────────────────────────────────┤
│  已过期                    查看全部 → │  ← P1 分区 Feed
│  [横滑物品卡 × N]                     │
│  临期                      查看全部 → │
│  [横滑物品卡 × N]                     │
│  库存不足                  查看全部 → │
│  最近入库                  查看全部 → │
├─────────────────────────────────────┤
│  按空间（Phase 可选）      查看全部 → │  ← 借鉴 P1，数据来自 location API
│  [厨房 12] [卫生间 8] → 横滑          │     **不是** 邻里服务
└─────────────────────────────────────┘
```

**不要**：在首页加与物品无关的「邻里三分类」Mock。

### 4.2 顶栏「+」：物品动作，不是发服务

借鉴闲鱼 **P9 多入口弹层**，选项应对齐录入场景：

| 入口 | 路由 | 说明 |
|------|------|------|
| 添加入库 | `/items/add` | 主路径 |
| 扫码录入 | `/items/scan` | 降门槛（vision 极简录入） |
| 记一笔消耗 | 详情页快捷 / 弹层 | 可选，减少完整编辑 |

**不要**：「发布服务」「发布托管」—— 除非单独立项且后端就绪。

### 4.3 导航：单页 + 深页 Push

| 书旗/点评/闲鱼共性 | HomeStock 落地 |
|-------------------|----------------|
| 首屏浏览 | 首页四分区 |
| 深页列表 | `/items`、`/home/section/:type` |
| 个人资产 | `/profile/panel`（物品、提醒、家庭、设置） |
| 不做底 Tab 堆功能 | 已移除 ShellRoute，保持 |

## 五、分页面交互借鉴（Interaction）

### 5.1 首页

| 借鉴点 | 来源 | HomeStock 做法 |
|--------|------|----------------|
| 分区头：标题 + 弱色「查看全部」 | 书旗、点评 | `HomeSectionHeader` ✅ |
| 双排/单行横滑 | 书旗书架 | `HomeTwoRowScrollGrid` ✅ |
| 下拉刷新 | 三者 | `RefreshIndicator` + invalidate provider ✅ |
| 分区级骨架屏 | 书旗 shimmer | `HomeSectionShimmer`，形状贴近卡片 |
| 分区级错误不拖垮全页 | 点评列表三态 | 单区显示错误文案 + 重试 |
| 卡片副信息行 | 点评列表第二行 | **位置路径** / 剩余数量 ✅ 方向对 |
| 可选摘要条 | 自家 design doc | 「今日 2 过期 3 临期」→ `/alerts` |

### 5.2 搜索

| 借鉴点 | 来源 | HomeStock 热词示例（物品向） |
|--------|------|------------------------------|
| 搜索历史 + 清空 | 书旗、点评 | ✅ |
| 热门搜索 Chip | 点评 | `临期`、`低库存`、`厨房`、`牛奶` — **不是**「家政」 |
| 轮播占位 | 闲鱼 | 「搜索物品名称」「搜索存放位置」 |
| 推荐分区 | 书旗 | 「即将过期」「最近入库」横滑 — **物品 API** |
| 结果行：左图/图标 + 标题 + 副行 | 点评 | 物品名 + 位置 + 品牌 |
| 空结果行动 | 闲鱼 | 「手动添加 xxx」→ `/items/add` |
| 联动提示 | 自研 | 搜「牛奶」→ 提示「查看临期食品」/**不是**跳转邻里服务 |

### 5.3 物品列表 `/items`

| 借鉴点 | 来源 | HomeStock 做法 |
|--------|------|----------------|
| 顶部搜索 + 筛选 | 点评 | 搜索框 + FilterBottomSheet |
| 状态 Chip 横滑吸顶 | 点评 `keyboard_quick_tab` | 全部/使用中/已过期… |
| 分类/空间二级筛选 | 点评快筛 | 与 `categoryFilterProvider` 打通 |
| 触底加载 | 点评、闲鱼 | 分页 provider 已有，改滚动触发 |
| 列表三态 | 点评 | `AsyncListBody` 复用 |
| 卡片语义色 | 自家 | 过期红条/标签，而非促销标签 |

### 5.4 添加入库 `/items/add`

| 借鉴点 | 来源 | HomeStock 做法 |
|--------|------|----------------|
| 分步向导降压力 | 闲鱼发布 **结构** | Step1 扫码或选分类 → Step2 名称数量 → Step3 位置 → Step4 过期（可跳过） |
| 先图后文 | 闲鱼 | 可选拍照，不强制 |
| 草稿/失败可续 | 点评 UGC 草稿 **思路** | 本地草稿箱（未提交表单） |
| 10 秒录入目标 | 自家 vision | 扫码成功则预填，用户只确认过期+位置 |

### 5.5 物品详情

| 借鉴点 | 来源 | HomeStock 做法 |
|--------|------|----------------|
| 头图 + 核心字段 | 点评商户头 | 大图 + 名称 + 分类 + 位置 |
| 固定底栏 CTA | 点评底栏 | `[记消耗] [编辑] [提醒设置]` |
| 信息分组 | 点评详情 Tab | 购买 / 存储 / 时效 / 使用记录 |

### 5.6 提醒中心 `/alerts`

| 借鉴点 | 来源 | HomeStock 做法 |
|--------|------|----------------|
| Tab 分类型 | 书旗频道 Tab | 过期 / 库存 / 补购（已有 AlertTab） |
| 列表 + 批量已读 | 点评订单列表 | 保留 |
| 点条目进详情 | 通用 | → 物品详情 |

### 5.7 个人中心 `/profile/panel`

| 借鉴点 | 来源 | HomeStock 做法 |
|--------|------|----------------|
| Header：身份 + 家庭 | 闲鱼「我的」 | 头像、昵称、当前家庭 ✅ |
| 家庭共享数据 | **自研差异化** | 贡献度、录入/消耗 — 已有 API |
| 功能列表 | 点评设置列表 | 物品列表、提醒、位置、分类、家庭管理 |
| 可见范围切换 | 点评城市 | **仅当有多家庭时** → 切换家庭，不是「同小区」 |

## 六、Phase 路线图（对齐真实产品）

### Phase 1 — 体验统一（2 周）

**目标**：同一套主题 + 搜索/录入交互，**零虚假业务模块**

| # | 任务 | 借鉴 | 验收 |
|---|------|------|------|
| 1 | 全站 P0 页暖色化 | 书旗克制 UI | 首页/搜索/个人中心无卡通 |
| 2 | 搜索 idle：历史+热词+**物品推荐分区** | 点评+书旗 P4 | 热词全是物品/场景词 |
| 3 | 「+」弹层：入库/扫码/消耗 | 闲鱼 P9 | 无「发布服务」 |
| 4 | 物品卡片 P5 完整（位置+状态） | 点评 | 副信息是位置/数量 |
| 5 | **移除** 邻里 Mock 模块与相关路由 | — | 首页仅物品分区 |

### Phase 2 — 核心路径打磨（2–4 周）

| # | 任务 | 借鉴 | 验收 |
|---|------|------|------|
| 1 | 物品列表：筛选 Chip + 吸顶 + 触底加载 | 点评 P6 | `/items` |
| 2 | 添加入库分步向导 | 闲鱼 P8 结构 | 主路径 ≤4 步 |
| 3 | 详情页底栏 CTA | 点评 | 记消耗/编辑 |
| 4 | 列表/搜索 `AsyncListBody` 三态统一 | 点评 P7 | 空态有引导动作 |
| 5 | 可选：首页「按空间」横滑分区 | 书旗 P1 | 数据来自 location |

### Phase 3 — 差异化与智能（后续）

| # | 任务 | 说明 |
|---|------|------|
| 1 | 家庭协作深化 | 谁录入、谁消耗、贡献排行 — **自研** |
| 2 | 搜索 → 场景联动 | 搜「厨房」→ 该空间物品；搜「过期」→ 过滤 — **不是** 外链服务 |
| 3 | 今日待办摘要条 | 自家 design doc |
| 4 | 录入草稿 / 扫码预填 | vision 极简录入 |
| 5 | 统计与浪费洞察 | vision 阶段三 |

## 八、对错误实现的修正说明

此前实现中以下内容 **不符合本产品**，应回退或改写：

| 错误内容 | 应改为 |
|----------|--------|
| 首页「邻里」层：托管/家政/门店 Mock | 删除；或改为「按空间」物品分区（需 API） |
| `/services/*` 路由与发布向导 | 删除；+ 弹层仅保留物品动作 |
| 搜索热词「儿童托管、家政」 | 改为「临期、低库存、厨房、牛奶…」 |
| 搜索联动「去看邻里服务」 | 改为「查看临期物品 / 该空间物品」 |
| 个人中心「邻里可见范围」 | 改为「切换家庭」或移除 |
| `community` 模块 Mock 数据 | 移除；保留 `communityWarm` **主题名** 即可 |

**可保留的通用基础设施**（与业务无关）：

- `CommunityScaffold`（建议 rename → `WarmScaffold`）
- `TagChip` / `FilterChipBar` / `AsyncListBody`
- 搜索页结构（历史 + 热词 + 推荐）
- 「+」弹层 **模式**（换选项即可）

## 十、总结

| App | 对 HomeStock 的唯一价值 |
|-----|-------------------------|
| **书旗** | 教首页「怎么逛」— 分区 + 横滑 + 查看全部 |
| **大众点评** | 教列表/搜索「怎么筛、怎么读卡片」— 副信息行、Chip、三态 |
| **闲鱼** | 教录入「怎么降低发布压力」— 多入口、分步、占位引导 |

**HomeStock 不需要变成点评或闲鱼。**  
我们要的是：**让管物品这件事，用起来像成熟 App 一样顺。**
