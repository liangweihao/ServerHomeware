# 添加物品页交互改版 — 设计规格

## 一、技术开发文档

### 背景

现版 `ItemFormView` 7 区块全展开，录入路径长。产品方确认：干净 UI、首屏关键字段、业务驱动折叠。

### 已确认决策（2026-06-22）

1. 首屏保留「放在哪」一行
2. 首屏「+ 添加照片」小入口
3. 选分类后自动展开对应折叠
4. 单位选盒/箱等时，首屏轻量露出「每盒含 n 个」

### 产出

- `doc/design/add-item-redesign.md` — 完整线框、分类策略表、字段映射、开发影响范围

### 影响范围

- 设计文档；**尚未改代码**
- 后续实现主要动 `item_form_view.dart`、`item_form_controller.dart`

## 二、提测文档（设计评审）

| 评审点 | 内容 |
|--------|------|
| 首屏字段 | 名称、分类、数量、单位、位置、照片入口 |
| 食品选分类 | 应自动展开「保质期与过期」 |
| 日用选分类 | 应自动展开「库存与补货」 |
| 电器选分类 | 应自动展开「购买记录」 |
| 单位选「盒」 | 首屏出现「每盒含」一行 |
| 手风琴 | 同时仅一个折叠展开 |
