## 📌 需求概述

实现一个「切换家庭」底部弹窗组件，支持查看、切换、删除家庭，以及创建/加入家庭的入口。要求 UI 精致现代，交互流畅带动效。

---

## 🎨 设计风格要求

- **风格**：iOS 风格底部弹出面板（Bottom Sheet），圆角卡片，毛玻璃遮罩
- **配色**：主色 #4F46E5（靛蓝），成功色 #10B981，危险色 #EF4444，背景 #F9FAFB
- **圆角**：弹窗顶部 24px，卡片 16px，按钮 12px
- **动效**：弹窗从底部滑入（cubic-bezier 弹性曲线），遮罩渐显，列表项有 hover/active 反馈
- **顶部拖拽条**：居中灰色小横条，暗示可下拉关闭

## 🔄 交互流程

### 1. 打开弹窗
- 触发方式：首页点击家庭名称区域
- 遮罩：背景变暗 50% + backdrop-filter: blur(8px)
- 弹窗：从底部滑入，duration 400ms，带回弹感

### 2. 切换家庭
| 步骤 | 行为 | 反馈 |
|------|------|------|
| 点击目标家庭卡片 | 卡片出现按下态（缩小 0.98） | - |
| 确认切换 | 弹窗内显示全屏 loading 蒙层 | 居中显示旋转 icon + "切换中..." |
| 切换成功（模拟 800ms） | 弹窗关闭 | Toast 提示："已切换到「老家」" ✓ |
| 切换失败 | 弹窗保持 | Toast 提示："切换失败，请重试" ✗ |

### 3. 更多操作菜单（点击 ··· 按钮）
弹出气泡菜单（Popover），选项：
- **编辑家庭** → 暂不实现，置灰
- **删除家庭** → 触发删除确认流程（见下方）

### 4. 删除家庭流程 ⚠️

**二次确认弹窗（居中 Dialog）：**

```
┌────────────────────────────────────┐
│                                    │
│         ⚠️ 删除家庭               │
│                                    │
│   确定要删除「老家」吗？           │
│                                    │
│   删除后该家庭下的所有物品数据     │
│   将永久丢失，且无法恢复。         │
│                                    │
│   请输入家庭名称以确认：           │
│   ┌──────────────────────────┐     │
│   │  请输入「老家」           │     │  ← 输入确认（防误触）
│   └──────────────────────────┘     │
│                                    │
│   [取消]          [确认删除]       │  ← 确认按钮默认禁用，输入正确后变红可点击
│                                    │
└────────────────────────────────────┘
```

**删除规则：**
- 当前正在使用的家庭**不允许删除**，··· 菜单中「删除」置灰，hover 提示 "请先切换到其他家庭"
- 仅**创建者**可删除家庭，非创建者不显示删除选项
- 家庭内只有 1 个家庭时，不允许删除（至少保留一个）

**删除交互：**
| 步骤 | 反馈 |
|------|------|
| 输入名称匹配 | 「确认删除」按钮变为红色可点击 |
| 点击确认删除 | 按钮变为 loading 态 "删除中..." |
| 删除成功 | Dialog 关闭，家庭列表移除该项（带滑出动画），Toast "已删除「老家」" |
| 删除失败 | Toast "删除失败，请重试" |

### 5. 关闭弹窗
- 点击遮罩区域
- 点击右上角 ✕ 按钮
- 下拉拖拽超过阈值（100px）松手关闭
- 关闭动效：弹窗下滑 + 遮罩渐隐

## 🧩 组件状态

### 家庭卡片状态

| 状态 | 样式 |
|------|------|
| 当前家庭 | 左侧 3px 主色竖线，背景 #EEF2FF，右上角「✓ 当前」标签（主色底白字） |
| 其他家庭（默认） | 白色背景，1px #E5E7EB 边框 |
| 其他家庭（hover） | 背景 #F9FAFB，边框色加深 |
| 其他家庭（按下） | transform: scale(0.98)，背景 #F3F4F6 |

### Toast 组件
- 位置：屏幕顶部居中，距顶 60px
- 样式：深色背景圆角胶囊，白色文字，左侧带状态 icon
- 动效：从顶部滑入，2s 后自动滑出消失

## ⚙️ 技术要求

- 纯前端原型，HTML + CSS + JavaScript 单文件
- 移动端优先，宽度适配 375px - 430px，居中展示
- 所有交互状态可演示（切换、删除、Toast、loading）
- 动画使用 CSS transition / animation，流畅 60fps
- 不依赖任何外部库
