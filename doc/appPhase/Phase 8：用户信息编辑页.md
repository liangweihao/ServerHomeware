## 一、头像位置与状态

```
首页 AppBar 右侧：

┌─────────────────────────────────────────┐
│ 📍 我的家                     🔔 3  👤   │
│                                    ↑     │
│                              用户头像     │
└─────────────────────────────────────────┘

头像样式：
- 尺寸：32×32 圆形
- 有头像：显示用户上传的头像图片
- 无头像：显示昵称首字（如"妈"），背景主色浅色(primary100)，文字主色
- 在线状态：右下角小绿点（可选，多人协作时表示在线）
```

## 七、面板动画与手势

### 7.1 打开动画

```
点击头像后：
1. 头像有按压缩放反馈（0.9, 100ms）
2. 右侧面板从右边缘滑入（300ms, ease-out）
3. 左侧主页面加暗遮罩（渐显到 50% 黑色, 200ms）
4. 面板宽度：屏幕宽度的 80%（最大320px）

面板圆角：左侧两角 16px 圆角
面板阴影：shadow-xl（较重阴影，体现层级）
```

### 7.2 关闭方式

```
三种关闭方式：
1. 点击左侧暗色遮罩区域
2. 从面板左边缘向右滑动（>100px触发关闭）
3. 点击面板内的路由跳转（跳转后自动关闭）

关闭动画：
- 面板向右滑出（250ms, ease-in）
- 遮罩渐隐（200ms）
```

### 7.3 面板内滚动

```
- 面板内容超出屏幕时可纵向滚动
- 滚动时头像区域可以有吸顶效果（缩小为32px头像+昵称一行）
- 退出登录按钮始终固定在面板底部
```

┌──┐

```

### 同步状态指示

```
头像外圈环形：
- 同步中：外圈旋转的蓝色弧线（像loading但很细）
- 同步完成：无
- 同步失败：外圈变红色 + 点击显示"同步失败，点击重试"

┌────┐
│ 👤 │ ← 正常
└────┘

┌──◠─┐
│ 👤 │ ← 外圈蓝色弧线旋转 = 同步中  
└────┘

┌──🔴─┐
│ 👤  │ ← 外圈红色 = 同步失败
└─────┘
```

## 十一、风格总结

```
面板风格要点：
- 背景：纯白
- 头像区域有轻微渐变背景（primary50 → white，高度120px）
- 卡片内容区：white 背景 + 1px gray200 边框 + 12px 圆角
- 分割线：gray200，左右不顶到边（左右留16px）
- 列表项高度：56px
- 所有可点击元素有点击态（背景变gray50）
- 退出登录：文字用 danger 色，无背景
- 整体内边距：左右 20px

### 12.5 状态转换流程
```
进入页面
    ↓
显示加载状态（loading 动画）
    ↓
API 调用成功 → 显示正常内容
    ↓
API 调用失败 → 显示错误状态（含重新加载按钮）
    ↓
点击重新加载 → 重新调用 API
    ↓
成功 → 显示正常内容
失败 → 保持错误状态（可再次点击重新加载）
```

### 12.6 错误状态设计规范
| 状态 | 图标 | 文字样式 | 按钮样式 |
|------|------|----------|----------|
| 加载中 | ○○○ 旋转动画 | 无 | 无 |
| 网络错误 | ❌ 红色 | 红色文字 | 主色按钮 |
| 未登录 | 👤 灰色 | 灰色文字 | 主色按钮 |
| 未加入家庭 | 🏠 主色 | 主色文字 | 主色按钮组 |
| 暂无数据 | 📊 灰色 | 灰色文字 | 无 |
