# 全局视觉刷新（v0.1）

> **状态**：**Phase A 已落地代码**（2026-06-22，青松 `#3A9B8A`）。录入 / 首页 / 列表改版见各专项文档。

---

## 一、设计原则

| 原则 | 做法 |
|------|------|
| 干净 | 浅灰底 `#FAFAFA`、白卡片、少描边、无大面积渐变 |
| 色彩有吸引力 | **主色**用于按钮/选中/链接；**分类色**用于 Chip 与标签 |
| 不花里胡哨 | 不用霓虹色、不用多色渐变按钮、装饰性 emoji 标题收敛 |

---

## 二、主色方案（推荐）

在「柔和、偏自然、适合家庭场景」前提下，推荐 **青松 Teal** 作为全局主色（替代 Material 蓝 `#2196F3`）：

| Token | 旧值 | **新值（推荐）** | 用途 |
|-------|------|------------------|------|
| `primary` | `#2196F3` | **`#3A9B8A`** | 主按钮、Tab 选中、FAB、链接 |
| `primaryDark` | `#1976D2` | **`#2D7F71`** | 按下态、AppBar 强调 |
| `primaryLight` | `#BBDEFB` | **`#A8D5CC`** | 次要按钮底、浅色标签 |
| `primaryLighter` | `#E3F2FD` | **`#E8F5F2`** | 选中背景、弱强调区块 |
| `info` / `infoLight` | 同旧蓝 | **同 primary 系** | 信息态与主色统一 |

### 为何选 Teal

- 比纯蓝**更柔和**，不刺眼
- 与「家居 / 收纳 / 健康」气质更贴
- 与分类色（食品橙、药品紫等）**对比清晰**，不会抢分类 Chip 的识别度
- 与日用清洁分类色 `#4DB6AC` 同色系但更深一档，主色仍可读

### 备选（若你更想要偏冷）

| 名称 | primary | 气质 |
|------|---------|------|
| 雾蓝 Soft Blue | `#5B8DEF` | 更接近常见 App，柔和蓝 |
| 藕紫 Muted | `#7B6FA6` | 更有辨识度，但略偏「工具感」 |

> **请确认**：已采用 **青松 `#3A9B8A`**；备选雾蓝/藕紫见下文。

### 语义色（建议不改）

成功 `#4CAF50`、警告 `#FF9800`、危险 `#F44336` — 用户已形成「红过期、橙偏低」认知，保持不动。

## 三、全局落地范围

主色替换后，以下位置**自动或需抽查**跟随 `AppColors` / `ThemeData`：

| 层级 | 文件 / 位置 |
|------|-------------|
| Token 真源 | `lib/core/constants/app_colors.dart` |
| Material 主题 | `lib/core/theme/app_theme.dart`（`primaryColor`、`ColorScheme`、`InputDecoration` focusedBorder、`BottomNavigationBar`、`FAB`） |
| 组件 | `AppButton` primary / secondary、`AppTag` info、`FilterChip` 选中态 |
| 页面 | TabBar、进度条主色、链接文字、`RefreshIndicator` |
| 硬编码 | 全局搜索 `0xFF2196F3`、`AppColors.primary` 误用 `Colors.blue` |

**不在此次改色**：各分类在数据库中的 `color` 字段（食品橙、药品紫等）— 继续独立，形成「主色 + 分类彩」双层体系。

## 四、与录入页的关系

| 元素 | 规则 |
|------|------|
| 分类 Chip | 底色用**分类色**浅化；选中描边 2px 用 **`primary`** |
| 主折叠左侧色条 | 用**分类色**（业务相关） |
| 保存 / 保存并继续 | 主按钮 `primary`；次按钮 `secondary`（`primaryLight` 底） |
| 输入框聚焦 | `focusedBorder` → `primary` |
