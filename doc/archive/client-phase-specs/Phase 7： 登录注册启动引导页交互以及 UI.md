```

│                                         │
│             HomeStock                   │  ← App 名称，h2Bold

│                                         │
│                                         │
│            ●●●  加载动画                │  ← 三个点跳动或呼吸圆环
│                                         │
│                                         │
│                                         │
└─────────────────────────────────────────┘

- 背景：纯白 或 非常浅的主色渐变（#E3F2FD → #FFFFFF）

- 动画：Logo 从 0.8 缩放到 1.0 + 渐显（300ms）
```

## 九、交互细节

### 9.1 输入验证规则

| 字段 | 验证规则 | 错误提示 |
|------|----------|---------|
| 手机号 | 11位数字，1开头 | "请输入正确的手机号" |
| 验证码 | 6位数字 | "验证码为6位数字" |
| 密码 | ≥8位，含字母+数字 | "密码需8位以上，包含字母和数字" |
| 确认密码 | 与密码一致 | "两次密码不一致" |
| 昵称 | 2-10个字符 | "昵称需2-10个字符" |
| 家庭名称 | 2-15个字符 | "家庭名称需2-15个字符" |
| 邀请码 | 8位字母+数字 | "邀请码为8位字母和数字" |

### 9.2 验证码按钮状态

```
默认状态：[获取验证码]  — 主色文字，可点击
发送中：  [发送中...]   — 灰色，不可点击，显示loading
倒计时：  [52s后重新获取] — 灰色，不可点击，倒计时60秒
可重发：  [重新获取]    — 主色文字，可点击
```

### 9.3 密码强度指示（注册页）

```
输入密码时下方显示强度条：

弱   ━━░░░░░░░░░░  （红色，仅数字或仅字母）
中   ━━━━━━░░░░░░  （橙色，字母+数字但<10位）
强   ━━━━━━━━━━━━  （绿色，字母+数字+≥10位或含特殊字符）
```

### 9.4 错误状态展示

```
字段级错误：
┌─────────────────────────────────┐
│ 138123456                       │  ← 输入框边框变红
└─────────────────────────────────┘
  ⚠️ 请输入正确的手机号              ← 红色小字，输入框下方

接口级错误（如密码错误）：
┌─────────────────────────────────┐
│  ⚠️ 手机号或密码错误，请重试     │  ← 页面顶部红色提示条
└─────────────────────────────────┘
  3秒后自动消失 或 点击关闭

网络错误：
  弹出 SnackBar："网络连接失败，请检查网络" + [重试]按钮
```

### 9.5 按钮加载状态

```
点击登录/注册后：
┌─────────────────────────────────┐
│        ◌  登录中...              │  ← 按钮变灰，显示loading圈+文字
└─────────────────────────────────┘
- 禁止重复点击
- 所有输入框禁用
- 3秒超时提示"请求超时，请重试"
```

## 十、视觉风格要点

### 10.1 整体风格

```
关键词：干净、温暖、信赖感

- 背景：纯白（#FFFFFF），不用灰色背景
- 大量留白，不拥挤
- 圆角柔和（输入框8px，按钮8px，卡片12px）
- 无多余装饰线条
- 重点操作按钮用主色（蓝#2196F3），有分量感
- 次要操作用灰色描边或纯文字
- 文字层次分明：标题黑色(gray900)，说明灰色(gray500)
```

### 10.2 登录页特有风格

```
- Logo区域占顶部 25% 空间（不要太大）
- 表单区域居中偏上（视觉重心在上方1/3处）
- 输入框之间间距 20px
- 主操作按钮高度 48px，圆角8px，全宽
- "忘记密码"和"注册"等次要操作用纯文字链接
- 底部协议文字用最小字号(10px)，不抢注意力
- 页面不需要滚动（一屏内放下所有内容）
```

### 10.3 输入框风格

```
默认状态：
- 背景：白色
- 边框：1px #E0E0E0
- 圆角：8px
- 高度：48px
- 左侧内边距：16px
- placeholder：14px #BDBDBD

聚焦状态：
- 边框：2px #2196F3（主色）
- 轻微阴影：0 0 0 3px rgba(33,150,243,0.1)

错误状态：
- 边框：2px #F44336（红色）
- 下方错误文字：12px #F44336

禁用状态：
- 背景：#F5F5F5
- 文字：#BDBDBD
```

### 10.4 动画

```
页面进入：从右侧滑入（300ms ease-out）
输入框聚焦：边框颜色过渡（200ms）
按钮按下：缩放0.96（100ms）
错误抖动：输入框左右抖动2次（300ms）— 输入错误时
成功页面：✓图标从0缩放到1 + 弹性动画（500ms spring）
验证码输入：每输入一位，方框有轻微缩放反馈
```

## 页面流程

启动页(1.5s) → 检查token：
  - 有效 → 主页
  - 无效/首次 → 欢迎页(仅首次) → 登录页

登录页：
  - 手机号+密码登录 → 成功 → 主页
  - 验证码登录 → 验证码页 → 成功 → 主页
  - 去注册 → 注册页

注册页：
  - 填写信息 → 注册成功 → 创建/加入家庭选择页
  - 创建家庭 → 填写家庭名+选房间 → 主页
  - 加入家庭 → 输入邀请码 → 主页

- 输入框间距20px
- 页面不需要滚动（如果键盘弹起，使用 SingleChildScrollView 防溢出）

## 组件要求

### PhoneInput
- 左侧固定显示"🇨🇳 +86"（灰色分隔线隔开）
- 右侧手机号输入，数字键盘
- 11位自动停止输入
- 验证：1开头的11位数字

### CodeInput
- 6个独立方框（40×48每个），间距12px
- 输入一位自动跳转下一格
- 删除自动回退上一格
- 全部输入完成触发 onCompleted 回调
- 当前聚焦格底部有主色下划线

### PasswordInput
- 右侧眼睛图标切换可见/隐藏
- 下方密码强度条（仅注册页显示）
- 强度计算：纯数字或纯字母=弱(红)，混合<10位=中(橙)，混合≥10位=强(绿)

### AuthButton
- 属性：label, onPressed, isLoading
- isLoading=true时：禁用+显示小圆形loading+文字变"XXX中..."
- 禁用时：背景变为 gray300
