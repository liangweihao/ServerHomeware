# 首页与物品列表 — 交互改版规格（v0.1）

> **状态**：设计稿，待评审。依赖 [visual-refresh.md](visual-refresh.md) 青松主色（已落地代码）。  
> **关联 PRD**：[PRD-home-notification-center.md](../product/prd/PRD-home-notification-center.md)（首页 🔔）

---

## 一、改版原则（与录入页一致）

| 原则 | 首页 / 列表落地 |
|------|----------------|
| 干净 | 减少 emoji 段落标题；用语义图标或纯文字小标题 |
| 色彩有吸引力 | **语义色**用于统计卡（过期红、库存橙）；**分类色**用于列表标签；**primary** 仅用于操作与选中 |
| 不花里胡哨 | 统计卡保留浅色底但降低饱和度；卡片阴影统一 `0.04` |
| 第一眼关键信息 | 首页：今天要处理什么；列表：找物品 + 快速筛选 |

### 2.1 现状问题

| 问题 | 位置 |

### 2.3 统计卡（StatCard）视觉调整

| 项 | 现版 | 目标 |
|----|------|------|
| 背景 | `dangerLight` 等整块浅色 | **白底** + 左侧 **4px 色条**（danger/warning/info/success） |
| emoji | 22px 在标题旁 | 改为 **Material Icons** 或保留小 emoji 仅图标位 |
| 数字 | 黑色 bold | 保持；副标题 `textHint` |

### 2.4 AppBar

- 去掉标题前 🏠；家庭名单击 → 切换家庭 sheet（已有 `profile/panel` 能力可对齐）
- 🔔：按 [PRD-home-notification-center.md](../product/prd/PRD-home-notification-center.md) 实现，Badge 与 Tab 提醒数一致
- 搜索、头像保持

### 2.5 「今日待办」摘要条（新增，可选 Phase）

- 仅当 `expiringCount + lowStockCount > 0` 显示
- 单行，`primaryLighter` 底，点整行 → `/alerts`
- 与下方 4 格统计不重复计数展示（摘要条 OR 4 格，二选一亦可 — **待确认**）

## 三、物品列表 `/items` — 现状 vs 目标

### 3.1 现状问题

| 问题 | 说明 |
|------|------|
| 搜索 + 筛选占两行白条 | 首屏列表区域偏小 |
| 仅状态 Chip，无分类筛选 | `categoryFilterProvider` 已有但未 UI 暴露 |
| 筛选 Chip 选中=整块 primary 填色 | 干净风下略重 |
| ItemCard 信息密度 | 可加强「过期/库存」视觉层次 |

### 3.2 目标结构

```
┌─────────────────────────────────────────┐
│  物品                          [扫码]    │  ← 可选：标题行 + 扫码快捷
│  ┌─────────────────────────────────┐    │
│  │ 🔍 搜索名称、品牌…          ≡    │    │  ≡ 打开 FilterBottomSheet
│  └─────────────────────────────────┘    │
│  (全部)(使用中)(已过期)…  + (分类 ▼)     │  ← 状态 Chip + 分类入口
│─────────────────────────────────────────│
│  ┌─────────────────────────────────┐    │
│  │ 🖼️ 蒙牛纯牛奶        [食品]     │    │
│  │     厨房›冰箱          3 盒      │    │
│  │     ─────────────  还剩 2 天 🔴  │    │  ← 细进度或标签
│  └─────────────────────────────────┘    │
│                              [FAB +]    │
└─────────────────────────────────────────┘
```

### 3.3 搜索栏

- 与背景融合：`fillColor: background`，外层无独立白 Container（或合并为一块）
- 右侧 **筛选** 图标 → 现有 `FilterBottomSheet`（状态/位置/分类/排序）

### 3.4 筛选 Chip 样式（青松体系）

| 状态 | 样式 |
|------|------|
| 未选中 | `gray100` 底 + `textSecondary` |
| 选中 | `primaryLighter` 底 + `primaryDark` 字 + **无**整块 primary 填色 |

### 3.5 分类筛选

- Chip「分类 · 全部」或当前分类名 → 底部 sheet 选分类
- 与 `categoryFilterProvider` 联动

### 3.6 ItemCard 微调

| 项 | 目标 |
|----|------|
| 分类 | 小 `AppTag`，用分类色浅底 |
| 数量 | 保持 primary 色数字 |
| 过期 | 右侧 badge，danger/warning，非整块背景 |
| 阴影 | 与 StatCard 统一 `0.04` |

### 3.7 FAB

- 保持 primary 青松色
- 长按或 secondary 入口：扫码（`/items/scan`）— 可选
