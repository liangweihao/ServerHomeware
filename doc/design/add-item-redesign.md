# 添加物品页 — 交互改版规格（v0.1）

> **状态**：Phase C 已落地（2026-06-22）。  
> **决策记录**：2026-06-22 与产品方确认首屏、折叠、分类联动、包装规格露出规则。  
> **现版实现**：`HomeWareClient/lib/presentation/items/item_form_view.dart`

---

## 一、改版目标

1. **首屏只解决「入库最小闭环」**：名称 + 分类 + 数量 + 位置 + 保存
2. **次要信息折叠**，按分类自动展开最相关的一块
3. **视觉干净**：少大标题、多留白；色彩来自分类 Chip 与主按钮
4. **学习成本低**：默认折叠有摘要；保存不强制填折叠内字段

---

```
┌─────────────────────────────────────────┐
│ ←  添加物品                      保存   │
│─────────────────────────────────────────│
│  名称 *                                  │
│  ┌─────────────────────────────────┐    │
│  │                                 │    │
│  └─────────────────────────────────┘    │
│                                         │
│  分类 *                                  │
│  [最近使用 Chip…]  [🍎食品] [🧴个护] …   │
│  或点击「全部分类」打开现有 CategorySelector │
│                                         │
│  数量   [ − ]  1  [ + ]     单位 [件 ▼] │
│  ┌─ 仅当单位为盒/箱/提/板/袋/包/瓶 时 ─┐   │
│  │ 每盒含  [ − ] 12 [ + ]  个          │   │  ← 轻量一行，见 §2.3
│  └─────────────────────────────────────┘   │
│                                         │

│                                         │
│  ┌─ 折叠区（仅一块默认展开，见 §三）────┐   │
│  │  ▼ …                               │   │
│  └─────────────────────────────────────┘   │
│  ┌─────────────────────────────────────┐   │
│  │  ▶ …                               │   │
│  └─────────────────────────────────────┘   │
│                                         │
```

### 2.1 首屏字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 名称 | 是 | 同现版 |
| 分类 | 是 | 优先横向 Chip（一级分类 + 最近使用）；完整树仍用 `CategorySelector` |
| 数量 | 否 | 默认 1，`QuantityStepper` 紧凑单行 |
| 单位 | 否 | 默认「件」，下拉 |
| 放在哪 | 否 | 一行 `LocationPicker`，展示 `fullPath` 或「未选择」 |
| 照片 | 否 | 「+ 添加照片」单行；已有图时显示「已 n 张」可点进管理 |

### 2.2 首屏不放

品牌、购买日期/渠道/单价、生产日期/保质期、容器、位置照片、提醒细调、备注、完整包装表单。

### 2.3 包装规格 — 首屏轻量露出

**触发条件**：单位 ∈ `盒 | 箱 | 提 | 板 | 袋 | 包 | 瓶`

**首屏追加一行**（紧贴数量行下方）：

```
每{单位}含  [ − ] {packageQuantity} [ + ]  {内单位 ▼}
```

- `packageQuantity` 默认 1，内单位默认「个」
- 数据映射现版：`package_unit` = 当前单位，`package_quantity` = 每包装含量，`unit` = 内单位
- 总量提示（可选一行小字）：`共 12 个（1 盒 × 12 个）`

**未触发时**（单位为 件/个/条…）：包装逻辑不显示；若 power user 需要，在「更多」折叠内可手动开启「按包装录入」。

### 2.4 照片入口

- 单行：`OutlinedButton` 或 `TextButton` + 图标，非 5 格大图区
- 点击 → 底部 sheet：拍照 / 相册（同现版）
- 已有图片 → 跳转横向缩略图管理（最多 5 张），可在 sheet 内完成

## 三、折叠分区（4 + 1）

| ID | 折叠标题 | 包含字段 | 默认 |
|----|----------|----------|------|
| `expiry` | 保质期与过期 | 生产日期、保质期选项、过期日期、过期提前提醒天数 | 收起 |
| `stock` | 库存与补货 | 库存预警数量（safety_stock） | 收起 |
| `purchase` | 购买记录 | 单价、购买日期、购买渠道、品牌 | 收起 |
| `locationDetail` | 存放详情 | 容器名称、位置参考照片 | 收起 |
| `more` | 更多 | 备注；完整包装录入（非盒箱单位时）；提醒细项冗余入口 | 收起 |

**折叠标题右侧摘要**（收起时）：

| 折叠 | 摘要示例 |
|------|----------|
| expiry | `未设置` / `2026-07-01 到期` |
| stock | `低于 1 件提醒` |
| purchase | `未填写` / `¥12.5 · 盒马` |
| locationDetail | `未填写` / `蓝色收纳箱` |
| more | `无备注` |

### 3.1 手风琴规则

- **同时最多展开 1 个折叠**（点另一个则收起当前）
- **切换分类时**：收起全部 → **自动展开**该分类的主折叠（§四）→ 200ms 内平滑动画
- 用户手动收起后，同一会话内切换分类仍自动展开主折叠（避免与「自动展开」决策冲突）

## 四、分类 → 自动展开（按一级分类 parentId）

子分类继承父级策略；**下列子类覆盖父级**：

| 条件 | 自动展开 | 折叠排序（上→下） |
|------|----------|-------------------|
| 一级：食品饮料 `1` | **expiry** | expiry → stock → purchase → locationDetail → more |
| 一级：药品保健 `4` | **expiry** | expiry → stock → purchase → locationDetail → more |
| 子类：宠物食品、宠物药品 | **expiry** | 同食品 |
| 子类：奶粉/辅食（母婴） | **expiry** | 同食品 |
| 一级：日用清洁 `2` | **stock** | stock → expiry → purchase → locationDetail → more |
| 一级：个护美妆 `3` | **stock** | 同日用 |
| 子类：纸尿裤 | **stock** | 同日用 |
| 一级：家用电器 `5` | **purchase** | purchase → locationDetail → expiry → stock → more |
| 一级：数码配件 `9` | **purchase** | 同电器 |
| 一级：衣物/家居/书籍/运动/汽车/工具 `6–8,12–14` | **locationDetail** | locationDetail → purchase → stock → expiry → more |
| 一级：宠物用品 `10`（除食品/药品子类） | **stock** | stock → … |
| 一级：母婴 `11`（除奶粉辅食） | **stock** | stock → … |
| 一级：其他 `15` | **无自动展开** | purchase → locationDetail → expiry → stock → more |

### 4.1 分类 Chip 首屏展示

**已确认**：常用 **7 个一级分类** + **「全部分类」**；不铺 15 个。

```
第一行（有数据时）：最近使用 — 最多 3 个 Chip
第二行（固定）：     7 个常用一级 + [全部分类]
```

| 顺序 | 一级分类 | 图标 |
|------|----------|------|
| 1 | 食品饮料 | 🍎 |
| 2 | 日用清洁 | 🧹 |
| 3 | 个护美妆 | 🧴 |
| 4 | 药品保健 | 💊 |
| 5 | 家居日用 | 🛋️ |
| 6 | 家用电器 | 📺 |
| 7 | 母婴用品 | 🍼 |
| — | **全部分类** | 打开 `CategorySelector` |

数码、宠物、运动、汽车、工具、其他 → 仅从「全部分类」进入。

- Chip：分类 `color` 浅底 + 图标；选中描边 2px `primary`（见 [ui_system.md](ui_system.md)）
- 最近使用：本地 `categoryId`，最多 3 个

### 4.2 默认提醒（不展示也需写入）

| 场景 | expiry_alert_days | safety_stock |
|------|-------------------|--------------|
| 食品/药品/宠物食品/奶粉 | 7 | 1 |
| 日用/个护/纸尿裤 | 3 | 1 |
| 电器/数码 | 3 | 0（可不预警） |
| 其他 | 3 | 1 |

## 六、视觉要点（录入页）

| 元素 | 规格 |
|------|------|
| 背景 | `#FAFAFA`，折叠块白底 `16px` 圆角 |
| 分类 Chip | 使用分类 `color` 浅色底 + 深色字；选中描边 2px primary |
| 折叠 | 无粗「基本信息」类 h2；用 `ExpansionTile` 或自定义，左侧细色条表主折叠 |
| 主折叠展开 | 左侧色条用分类色，暗示「这块和当前分类相关」 |
| 主按钮 | 全宽 `primary` **保存入库** |
| 次按钮 | `secondary` **保存并继续**（底部双按钮保留，同现版 `add_item_page.dart`） |

全局主色见 [ui_system.md](ui_system.md)（默认 `utilityClean`：`primary #FF6633`，FAB `#FFDA44`）。

## 七、扫码入库

扫码进入添加页时：

- 名称、分类若条码 API 有返回则预填

- 食品类条码 → 自动展开 **expiry**
