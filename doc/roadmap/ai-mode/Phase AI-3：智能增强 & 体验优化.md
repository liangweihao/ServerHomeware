## 任务1：智能物品匹配

### 模糊匹配策略

用户说"酱油" → 数据库里是"海天生抽酱油500ml"
用户说"那个洗头的" → 匹配"海飞丝洗发水"
用户说"感冒药" → 匹配"布洛芬缓释胶囊"

匹配规则（优先级从高到低）：
1. 精确匹配 name
2. name LIKE '%关键词%'
3. 分类名匹配（"感冒药" → 药品分类下的物品）
4. 别名/同义词匹配（维护一个同义词表）
5. 大模型语义匹配（最后兜底）

### 歧义消解

当匹配到多个结果时：
- 如果 ≤ 3个：显示 ChoicePicker 让用户选
- 如果 > 3个：缩小范围追问

### 同义词表

创建可扩展的同义词映射：
```json
{
  "洗头的": ["洗发水", "洗发液", "洗发露"],
  "纸": ["抽纸", "卫生纸", "纸巾", "厨房纸"],
  "感冒药": ["布洛芬", "感冒灵", "泰诺"],
  "牙膏": ["牙膏", "牙粉"]
}
```

## 任务2：上下文记忆增强

### 指代消解

对话示例：
```
用户："牛奶还有多少"
AI："蒙牛纯牛奶还剩3盒"

用户："用掉一盒"   ← "一盒"指的是牛奶
AI：正确理解→ 记录牛奶使用1盒

用户："它什么时候过期"  ← "它"指的是牛奶
AI：正确理解→ 返回牛奶过期日期
```

实现方式：
- context.last_item_id 记录最近操作的物品
- 当用户说"它""那个""这个"时，引用 last_item_id
- 当用户说"也是"时，复用上一次的操作类型

### 会话跨轮次槽位保持

```
用户："买了牛奶"
AI："买了几盒？" (awaiting: quantity)

用户："6盒"  ← 不需要再说"6盒牛奶"，系统记住了在说牛奶
AI："好的，6盒牛奶。放在哪里？"

用户："冰箱"  ← 简短回答直接补充位置槽位
AI："已记录！6盒牛奶放入冰箱冷藏层 ✓"
```

## 任务3：智能默认值 & 学习

### 基于历史推断默认值

```
用户之前的行为：
- 牛奶总是放冰箱冷藏层
- 洗衣液总是放阳台储物柜
- 每次买牛奶都是6盒

所以当用户说"又买了牛奶"时：
AI："收到！蒙牛纯牛奶6盒，放冰箱冷藏层，对吗？"
- 自动填充了数量（6盒）和位置（冰箱）
- 只需用户确认即可
```

### 实现方式

为每个物品名称维护历史统计：

```sql
CREATE TABLE item_defaults (
  family_id INT,
  item_name VARCHAR(100),
  most_common_location_id INT,
  most_common_quantity INT,
  most_common_unit VARCHAR(10),
  avg_price DECIMAL(10,2),
  avg_shelf_life_days INT,
  occurrence_count INT,
  updated_at TIMESTAMP
);
```

每次成功入库后更新统计。当 occurrence_count >= 3 时，开始使用智能默认值。

## 任务4：主动建议 & 智能提醒

### 场景化主动提醒

**基于时间的建议：**
- 周六上午："周末了，要不要检查一下冰箱？上周买的蔬菜可能快要坏了 🥬"
- 月底："这个月食品支出比上月多了200块，要不要看看统计？📊"
- 物品入库7天后没有使用记录："上周买的XX还没用过呢，别忘了哦"

**基于行为的建议：**
- 用户连续3天记录使用了牛奶："牛奶消耗得挺快，按这个速度后天就没了，要加入购物清单吗？"
- 用户丢弃了过期物品："这个月已经丢了3件过期食品（¥47），建议下次少买点叶菜类 💡"

### 实现方式

在 Celery 定时任务中增加"智能建议生成"任务：
- 每天检查一次各种条件
- 生成建议存入 notifications 表
- App打开时在对话流中展示

## 任务5：快捷指令 & 语音快捷

### 预设快捷指令

对于高频简单操作，直接用规则匹配，不走大模型：

```python
QUICK_COMMANDS = {
    r"什么(快|要|即将)?过期": "query_expiring",
    r"(什么|啥)(快)?没了": "query_low_stock",
    r"购物清单": "generate_shopping",
    r"(今天|本周|这个月)花了多少": "query_statistics",
    r"所有物品": "list_all_items",
}
```

匹配到快捷指令 → 直接执行 Action → 跳过大模型调用
未匹配 → 走大模型流程

### 语音唤醒词（可选增强）

设置唤醒词"小管家"或"HomeStock"：
- 不需要按麦克风按钮
- 说"小管家，创可贴在哪" → 直接处理
- 使用 picovoice 或 snowboy 本地唤醒
