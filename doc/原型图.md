## 十四、设计规范建议

### 颜色系统

```
状态色：
🟢 正常/充足      #4CAF50
🟡 注意/偏低      #FF9800  
🔴 紧急/过期      #F44336
🔵 信息/操作      #2196F3
⚪ 默认/未设置    #9E9E9E
```

### 关键设计要点

| 原则     | 说明               |
| :----- | :--------------- |
| 一目了然   | 首页3秒内看到最重要的信息    |
| 操作最短路径 | 常用操作（使用、录入）不超过3步 |
| 容错友好   | 随时可修改、撤销         |
| 渐进披露   | 高级功能藏在深层，不干扰基础使用 |
| 情感化    | 适当的成就感（本月节省了¥XX） |

***

需要我进一步细化某个页面的交互细节，或者输出为具体的设计工具格式（如Figma组件描述）吗？
