## 任务1：语音识别服务（服务端）

### 方案：讯飞实时语音识别 WebSocket

创建 app/ai/speech_service.py：

**WebSocket 接口：WS /api/v1/chat/speech**

流程：
1. 客户端建立 WebSocket 连接（带 JWT 认证）
2. 客户端持续发送音频流（PCM 16bit 16kHz）
3. 服务端将音频转发给讯飞 WebSocket API
4. 讯飞返回实时识别结果
5. 服务端将中间结果实时回传客户端（用于显示实时文字）
6. 讯飞返回最终结果后：
   a. 将完整文本发给 AI 意图引擎
   b. 等待 AI 处理完成
   c. 将结构化响应发回客户端

消息格式：
客户端 → 服务端：
```json
{"type": "audio", "data": "base64编码的音频片段"}
{"type": "end"}
```

服务端 → 客户端：
```json
{"type": "partial", "text": "实时识别中间结果"}
{"type": "final_text", "text": "最终识别文本"}
{"type": "ai_response", "data": {完整的chat响应结构}}
{"type": "error", "message": "错误信息"}
```

### 备选方案：REST 模式

**POST /api/v1/chat/voice**

请求：multipart/form-data，audio 文件
响应：同 /chat/message 响应结构 + recognized_text 字段

## 任务2：Flutter 对话 UI

### 主界面改造

App 主界面从 Tab 导航模式改为对话模式：

```
主页面结构：
├── AppBar（简洁：App名 + 设置齿轮 + 快捷面板按钮）
├── 消息列表（主体区域，可滚动）
│   ├── AI 主动提醒卡片（每天首次打开时）
│   ├── 用户消息气泡
│   ├── AI 回复 + 动态UI卡片
│   └── 底部留白
├── 建议提示条（横向滚动的快捷建议）
└── 输入区（语音按钮 + 文字输入框 + 发送按钮）
```

### 消息类型渲染

根据响应中的 ui.type 动态渲染不同组件：
- **text_reply**：普通文字气泡
- **confirm_card**：成功确认卡片
- **item_card**：单物品详情卡片
- **item_list**：物品列表卡片
- **location_card**：位置路径高亮卡片
- **shopping_list**：购物清单卡片
- **statistics_chart**：内嵌小图表
- **form_request**：内嵌迷你表单
- **choice_picker**：选项按钮组


## 任务3：消息列表管理

### 数据结构

```dart
abstract class ChatMessage {
  String id;
  DateTime timestamp;
  MessageType type;
}

class UserMessage extends ChatMessage {
  String text;
  String? audioUrl;
}

class AssistantMessage extends ChatMessage {
  String text;
  String? ttsText;
  String emotion;
  UIComponent? uiComponent;
  List<String> suggestions;
  List<ActionButton> actions;
}

class SystemMessage extends ChatMessage {
  String title;
  UIComponent uiComponent;
}
```

### 消息持久化

- 本地缓存最近100条消息（SQLite 或 SharedPreferences）
- 可以离线查看历史对话
- 打开App时从服务端同步最新
